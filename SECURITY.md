# Security Policy

## Reporting a vulnerability

Do not publish exploitable security details in a public issue. Email `security@sendwaste.ai` with:

- the affected component;
- reproduction steps;
- potential impact;
- supporting evidence;
- a safe contact method.

## Initial security commitments

- least-privilege access;
- multifactor authentication for administrative accounts;
- secret management outside source control;
- encrypted transport and storage;
- audit logging for verified records and settlement changes;
- dependency and configuration review;
- backups and restoration testing;
- prompt triage of credible reports.
