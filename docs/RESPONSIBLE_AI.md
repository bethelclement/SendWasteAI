# Responsible AI

## Principle

SendWaste AI uses AI to support operational decisions. It does not allow a model to create, alter or certify recovery evidence without human verification.

## Intended uses

- rank open pickup requests;
- flag incomplete or inconsistent evidence;
- identify possible duplicate submissions;
- forecast collection demand;
- support route planning;
- draft reports from verified records.

## Prohibited uses

- inventing weights, collection events or impact figures;
- fully automated denial of collector payment;
- opaque scoring that cannot be reviewed;
- using sensitive personal data without a defined purpose;
- facial recognition or biometric surveillance;
- publishing predicted impact as measured impact.

## Human oversight

- authorised operators can inspect model factors;
- high-impact decisions require a human confirmation;
- overrides are recorded with a reason;
- users can report an error;
- model performance is reviewed against actual outcomes.

## Model monitoring

Track:

- false-priority and missed-priority rates;
- anomaly flag precision;
- forecast error;
- performance by district and customer type;
- override rate and reason;
- model and infrastructure cost per verified pickup.
